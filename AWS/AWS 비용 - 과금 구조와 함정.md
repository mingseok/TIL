```java

```

<br/>

한 달은 730시간으로 계산한다. `24 × 365 / 12`.

<br/>

작은 서비스의 최소 구성을 더해보면.

```java
EC2 t3.small        $19
RDS db.t3.micro     $19

NAT 게이트웨이       $43 + 처리량     (시간당 $0.059)
```

<br/>

앱 서버보다 NAT 게이트웨이가 두 배 비싸다.

앞의 VPC 글에서 본 대로 프라이빗 서브넷에서 밖으로 나가는 데 필요한 것인데, 작은 프로젝트에서는 이것 하나가 청구서의 절반이다.

## 데이터 전송

```java
들어오는 것                  무료
인터넷으로 나가는 것          GB 당 약 $0.126 (월 100GB 까지 무료)
가용영역 사이                 GB 당 $0.01 (양방향 각각)
리전 사이                    GB 당 $0.02 ~
같은 가용영역 안, 사설 IP     무료
```

<br/>

앞의 탄력적 IP 글에서 본 `VPC 안에서는 사설 IP 로` 가 여기서 돈이 된다.

같은 VPC의 두 서버가 퍼블릭 IP로 통신하면 인터넷으로 나갔다 들어온 것으로 쳐서 요금이 붙는다.

<br/>

동영상 서비스면 전송 요금이 컴퓨팅보다 크다.

1TB 나가면 $126이다. 앞의 CloudFront 글에서 본 CDN이 S3 직접 전송보다 GB당 단가가 낮고, 캐시가 오리진 전송을 줄인다.

<br/><br/>

## 켜져 있지 않아도 나가는 것

```java
EBS 볼륨         인스턴스를 stop 해도 디스크는 남아서 요금. gp3 GB 당 월 $0.08
스냅샷           찍어두고 잊는다. 쌓인다
탄력적 IP        인스턴스에 안 붙어 있으면 월 $3.6. 앞의 탄력적 IP 글
NAT 게이트웨이    트래픽 0 이어도 시간당 요금
ALB              트래픽 0 이어도 시간당 요금
CloudWatch 로그  보존 기간을 안 정하면 영구. 앞의 CloudWatch 글
RDS 스냅샷       인스턴스를 지울 때 "최종 스냅샷" 을 남기면 그것도 요금
```

<br/>

`인스턴스를 멈췼으니 요금이 안 나갈 것` 이 첫 번째 오해다. 컴퓨팅만 멈춘다.

<br/>

테스트로 만들어본 것을 지우지 않는 게 두 번째다. 특히 NAT와 ALB는 만들어놓고 잊기 쉽고, 만들어만 두면 월 $60이다.

<br/><br/>

## 프리티어의 끝


12개월이 지나면 알림 없이 유료로 넘어간다. 가입한 날을 기억해둔다.

## 알림을 건다

```java
AWS Budgets   - 월 $50 넘으면 이메일. 예측치가 넘을 것 같으면 미리
Cost Explorer - 서비스별, 태그별로 어디에 나갔는지
태그          - 자원마다 project=xxx, env=dev 를 붙여서 비용을 나눠 본다
```

<br/>

청구서는 다음 달에 온다. 이상한 것이 생겨도 한 달 뒤에 안다.

Budgets 경보를 걸어두면 며칠 안에 안다. 계정 만들고 제일 먼저 할 일이다.

<br/>

앞의 액세스 키를 코드에 넣지 않는 법 글에서 본 키 유출도 비용 경보로 발견되는 경우가 많다.

새 리전에 갑자기 인스턴스가 수십 대 떠서 청구액이 튀는 것이 첫 신호다.

## 정리

```java
세 축        - 컴퓨팅 시간, 저장 용량, 나가는 전송
숨은 비용     - NAT, ALB, 안 붙은 EIP, stop 한 EBS, 스냅샷, 영구 로그
전송         - 들어오는 건 무료, 나가는 건 유료. 내부 통신은 사설 IP 로
줄이기       - 지표 보고 크기 맞추기, 확실하면 약정, 개발 서버는 끈다
제일 먼저     - Budgets 경보. 청구서는 한 달 뒤에 온다
```

<br/>

단가는 바뀐다. 위 숫자는 계산 방법을 보기 위한 근사치고, 실제 견적은 AWS 요금 계산기로 낸다.
