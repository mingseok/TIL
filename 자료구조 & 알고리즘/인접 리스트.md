## 자바는 ArrayList 사용하자.

```java
import java.util.ArrayList;
import java.util.List;

import javax.xml.transform.stream.StreamSource;

public class eee {
    public static void main(String[] args) {

        // ArrayList 준비
        ArrayList<Integer> arrList = new ArrayList<Integer>();

        arrList.add(1);
        arrList.add(2);
        arrList.add(3);

        System.out.println(arrList.get(0)); // 1
        System.out.println(arrList.get(1)); // 2
        System.out.println(arrList.get(2)); // 3

        System.out.println(arrList); // [1, 2, 3]

        // 마지막 index 데이터 삭제
        arrList.remove(arrList.size() - 1);

        System.out.println(arrList.size()); // 2

        for (int i = 0; i < 10; i++) {
            arrList.add(5);
        }

        System.out.println(arrList.size()); // 12

    }
}
```

## 자바에서는 이걸 사용 remove() 메서드를 사용하자.
```java
import java.util.ArrayList;
import java.util.List;

public class eee {
    public static void main(String[] args) {

        // ArrayList 준비
        List<String> arrList = new ArrayList<String>();

        arrList.add("A");
        arrList.add("B");
        arrList.add("C");
        
        System.out.println("변경 전 : " + arrList); // [A, B, C]

        // 첫번째 index 데이터 삭제
        arrList.remove(0);

        System.out.println("첫번째 index 데이터 삭제 후 : " + arrList); // [B, C]

        // 마지막 index 데이터 삭제
        arrList.remove(arrList.size() - 1);
        
        System.out.println("마지막 index 데이터 삭제 후 : " + arrList); // [B]
    }
}
```

## 인접 리스트의 구현 (중요)

ArrayList 배열을 구현하는 방법
```java
ArrayList<Integer>[] arr = new ArrayList[100];

    for(int i = 0; i < 100; i++) {
        arr[i] = new ArrayList<Integer>();
    }
```

<br/>

그래프 저장할 때 항상 사용할 것이다.
```java
import java.util.*;
import java.util.ArrayList;;

      // 인접리스트의 구현
      //    1 --- 2
      //    |\   /
      //    | \ /
      //    3  4 --- 5 
      //    ㄴ ---- /

      // 1 : 2 3 4
      // 2 : 1 4
      // 3 : 1 5
      // 4 : 1 2 5
      // 5 : 3 4

      // 간선 
      // 5 6
      // 1 2
      // 1 3
      // 1 4
      // 2 4
      // 3 5
      // 4 5

public class ddd {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        ArrayList<Integer>[] myGraph = new ArrayList[100];

        for(int i = 0; i < 100; i++) {
            myGraph[i] = new ArrayList<Integer>();
        }

        int n = sc.nextInt();
        int m = sc.nextInt();

        for(int i = 0; i < m; i++) {

            // a와 b가 연결 되어 있음
            int a = sc.nextInt();
            int b = sc.nextInt();

            myGraph[a].add(b);
            myGraph[b].add(a);
        }

        for(int i = 1; i <= n; i++) {

            System.out.print(i + "(" + myGraph[i].size() + ")" + " : ");
            
            // myGraph[i] 의 의미는?? -> 모든 인접한 노드들을 담고 있는 배열이다.

            for(int j = 0; j < myGraph[i].size(); j++) {
                System.out.print(myGraph[i].get(j) + " ");
            }
            System.out.println();
        }
    }
}
```

## 궁금증!

```java
메모리를 얼마나 아끼나
```

간선 개수에만 비례한다.

```java
인접 행렬 - O(V²)
인접 리스트 - O(V + E)
```

<br/>

```java
정점 10,000 개, 간선 20,000 개

인접 행렬   - 1 억 칸
인접 리스트 - 정점 1만 + 간선 4만 (무방향이라 두 배) = 5만
```

<br/>

2000배 차이다.

<br/>

앞의 인접 행렬 글에서 본 대로 실제 그래프는 대부분 성기니,

인접 리스트가 기본이 되는 것이다.

## 대신 연결 여부 확인이 느리다

```java
adj[i][j]                    -> O(1)
adjList.get(i).contains(j)   -> O(차수)
```

<br/>

한 정점에 붙은 간선을 순서대로 훑어야 한다.

<br/>

이게 자주 필요하면 `Set` 으로 바꾼다.

```java
List<Set<Integer>> adj;
```

<br/>

앞의 해시(Hash) 글에서 본 대로 `contains` 가 `O(1)` 이 된다.

<br/>

메모리는 `List` 보다 더 쓴다. 해시 테이블의 여유 공간 때문이다.

## 자바에서 배열로 만들 때 제네릭이 걸린다

```java
List<Integer>[] adj = new List<Integer>[n];      // 컴파일 오류
```

<br/>

```java
generic array creation
```

<br/>

앞의 제네릭 글에서 본 타입 소거 때문이다.

<br/>

실행 시점에는 타입 정보가 없어서 배열이 자기 타입을 검사할 수 없다.

배열은 실행 중에 타입을 검사하는데 제네릭은 그 정보가 지워지니 충돌한다.

<br/>

우회 방법이 두 가지다.

```java
@SuppressWarnings("unchecked")
List<Integer>[] adj = new List[n];              // raw 타입으로 만든다

List<List<Integer>> adj = new ArrayList<>();    // 리스트의 리스트
```

<br/>

두 번째가 깔끔한데 조금 느리다.

<br/>

## 초기화를 빼먹는 실수

```java
List<Integer>[] adj = new List[n];
adj[0].add(1);        // NullPointerException
```

<br/>

배열만 만들고 각 칸을 안 채운 것이다.

```java
for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();
```

<br/>

`Map` 을 쓰면 이 문제가 없다.

```java
Map<Integer, List<Integer>> adj = new HashMap<>();
adj.computeIfAbsent(0, k -> new ArrayList<>()).add(1);
```

<br/>

앞의 Map 정리 글에서 본 `computeIfAbsent` 다.

없으면 만들어서 넣고 돌려주니 초기화를 따로 안 해도 된다.

<br/>

`getOrDefault` 를 쓰면 안 들어간다는 것도 그 글에서 확인했다.

<br/>

## 가중치를 담으려면 클래스가 필요하다

```java
class Edge {
    int to;
    int weight;
}

List<Edge>[] adj;
```

<br/>

`int[]` 두 개로 담을 수도 있는데 읽기 어려워진다.

```java
adj.get(i).get(j)[0]      // to
adj.get(i).get(j)[1]      // weight
```

<br/>

앞의 프로젝트 컨벤션에도 나오듯,

의미가 이름으로 드러나는 편이 낫다.

<br/>

## 다익스트라에서 이 구조를 쓴다

```java
PriorityQueue<Edge> pq = new PriorityQueue<>(Comparator.comparingInt(e -> e.weight));
```

<br/>

앞의 큐 글에서 본 `PriorityQueue` 와 짝을 이룬다.

```java
인접 리스트 - 지금 정점에서 갈 수 있는 곳만 본다
우선순위 큐 - 그 중 가장 가까운 곳부터 처리한다
```

<br/>

인접 행렬로 하면 매번 `n` 칸을 훑어야 해서 `O(V²)` 이 된다.

인접 리스트 + 우선순위 큐면 `O(E log V)` 다.

<br/>

성긴 그래프에서 `E` 가 `V²` 보다 훨씬 작으니 훨씬 빠른 것이다.

<br/>

## CSR 이라는 방식도 있다

배열 두 개로 인접 리스트를 표현하는 방법이다.

```java
int[] head;      // 각 정점의 간선이 시작하는 위치
int[] to;        // 간선의 도착점을 쭉 늘어놓은 것
```

<br/>

```java
정점 0 의 간선 = to[head[0]] ~ to[head[1] - 1]
```

<br/>

`List` 객체를 안 만드니 메모리를 훨씬 덜 쓰고,

나란히 붙어 있어서 캐시에도 잘 맞는다.

<br/>

앞의 인접 행렬 글에서 본 `1차원으로 펴는` 발상과 같다.

<br/>

대신 간선을 추가하려면 다시 만들어야 한다.

그래프가 안 바뀌는 상황에서만 쓸 수 있는 것이다.

<br/>

대회용 코드나 그래프 라이브러리 내부에서 쓴다.

실무 코드에서 직접 쓸 일은 거의 없다.
