## 깊이 우선 탐색의 구현

```java
import java.util.*;
import java.util.ArrayList;;

    // 깊이 우선 탐색 (DFS)
    // 1 ----- 2 ----- 6
    //  \     / \      |
    //   \   /   4 --- 5
    //    \ /   / \
    //     3 - 7 - 8 - 9

    // 순서
    // 1 -> 2 -> 3 -> 7 -> 4 -> 5 -> 6 -> 8 -> 9

    // 정점, 간선 표시 해주기. 
    // 9 12
    // 1 2
    // 1 3
    // 2 3
    // 2 4
    // 2 6
    // 3 7
    // 4 5
    // 4 7
    // 4 8
    // 5 6
    // 7 8
    // 8 9

    
public class ddd {

    // 전역 변수 -> 모든 함수에서 볼 수 있는 변수라고 한다.
    static private final int MAX = 100;
    static ArrayList<Integer>[] myGraph = new ArrayList[MAX];
    static boolean[] visited = new boolean[MAX];
    static int n;
    static int m;

    public static void DFS(int x) {
        // x부터 시작해서 DFS하여 그 순서를 출력하는 함수.
        // 단, visited에 방문 기록이 있음.

        visited[x] = true;
        System.out.print(x + " ");

        // myGraph[x] <- [1, 3, 4]
        for(int i = 0; i < myGraph[x].size(); i++) {
            int y = myGraph[x].get(i); // y 가 인접한 노드 한개 이다.
            // x와 y가 연결이 되어 있다.

            if(visited[y] == false) {
                DFS(y);
            }
        }
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        for(int i = 0; i < MAX; i++) {
            myGraph[i] = new ArrayList<Integer>();
        }

        n = sc.nextInt();
        m = sc.nextInt();

        for(int i = 0; i < m; i++) {

            // a와 b가 연결 되어 있음
            int a = sc.nextInt();
            int b = sc.nextInt();

            myGraph[a].add(b);
            myGraph[b].add(a);
        }

        DFS(1); // 1부터 시작해서 DFS한 결과를 출력!

    }
}
```

## 궁금증!

```java
재귀와 스택 구현이 방문 순서가 다르다
```

같은 그래프에서 돌려보면 순서가 달라진다.

```java
// 재귀
void dfs(int now) {
    visited[now] = true;
    System.out.print(now + " ");
    for (int next : adj[now]) {
        if (!visited[next]) dfs(next);
    }
}
```

```java
// 스택
stack.push(start);
while (!stack.isEmpty()) {
    int now = stack.pop();
    if (visited[now]) continue;
    visited[now] = true;
    System.out.print(now + " ");
    for (int next : adj[now]) {
        if (!visited[next]) stack.push(next);
    }
}
```

<br/>

스택은 나중에 넣은 것이 먼저 나오니, 인접 목록을 거꾸로 훑는 셈이 된다.

<br/>

재귀와 같은 순서를 내려면 거꾸로 넣어야 한다.

```java
for (int i = adj[now].size() - 1; i >= 0; i--) {
    stack.push(adj[now].get(i));
}
```

<br/>

앞의 스택 글에서 본 `오른쪽을 먼저 넣는` 이유가 이것이다.

<br/>

## 스택 구현에서 visited 검사가 두 번 필요하다

```java
int now = stack.pop();
if (visited[now]) continue;      // 꺼낼 때 한 번 더
```

<br/>

넣을 때 검사했는데도 또 해야 한다.

<br/>

같은 정점이 여러 경로로 스택에 들어갈 수 있기 때문이다.

```java
A 가 C 를 스택에 넣는다
B 도 C 를 스택에 넣는다      <- C 는 아직 안 꺼내져서 visited 가 false
```

<br/>

앞의 그래프 순회의 뜻 글에서 본 BFS의 문제와 같다.

<br/>

BFS는 넣을 때 표시해서 막는데, DFS 스택 구현은 그러면 순서가 달라진다.

그래서 꺼낼 때 한 번 더 확인하는 방식을 쓰는 것이다.

<br/>

## 재귀가 훨씬 짧고 읽기 쉽다

```java
재귀  - 4 줄
스택  - 10 줄 + 순서 뒤집기 + 중복 검사
```

<br/>

그래서 웬만하면 재귀로 쓴다.

<br/>

앞의 재귀함수 글에서 확인한 그 한계가 문제가 될 때만 바꾼다.

```java
StackOverflowError. 깊이 = 6308
```

<br/>

정점이 10만 개인데 한 줄로 이어져 있으면 재귀로는 못 푼다.

## 방문 표시를 안 하면 무한 루프

```java
void dfs(int now) {
    for (int next : adj[now]) {
        dfs(next);         // visited 검사가 없다
    }
}
```

<br/>

사이클이 있으면 영원히 돈다.

<br/>

트리에서는 부모로 돌아가는 것만 막으면 된다.

```java
void dfs(int now, int parent) {
    for (int next : adj[now]) {
        if (next != parent) dfs(next, now);
    }
}
```

<br/>

앞의 그래프 글에서 본 대로 트리에는 사이클이 없으니

`왔던 길로 안 돌아간다` 만 지키면 충분하다.

<br/>

`visited` 배열을 안 써도 되니 메모리가 준다.

<br/>

## 사이클을 찾으려면 상태가 세 가지여야 한다

```java
0 - 아직 안 봄
1 - 방문 중 (아직 안 나옴)
2 - 방문 완료
```

<br/>

```java
boolean dfs(int now) {
    state[now] = 1;
    for (int next : adj[now]) {
        if (state[next] == 1) return true;      // 사이클
        if (state[next] == 0 && dfs(next)) return true;
    }
    state[now] = 2;
    return false;
}
```

<br/>

`state == 2` 인 것을 다시 만나는 건 사이클이 아니다.

이미 처리가 끝난 다른 가지일 뿐이다.

<br/>

앞의 깊이 우선 탐색의 철학 글에서 본

`방문 중` 과 `방문 완료` 의 구분이 여기서 필요해진다.

<br/>

`boolean` 하나로는 이걸 표현할 수 없는 것이다.

<br/>

앞의 생성자 주입을 선택 글에서 본 스프링의 순환 참조 검사도

이 방식으로 동작한다.

```java
UnsatisfiedDependencyException
```

<br/>

지금 만들고 있는 빈을 다시 만들라는 요청이 오면 사이클인 것이다.
