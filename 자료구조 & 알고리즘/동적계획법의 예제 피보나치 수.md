## 이 두개는 점화식으로 구할 수가 없다. 왜??

F(1) 은 → “내 전번째가 F(0) 있기는 하지만, 전전번째가 없어서 안되고,

F(0) 는 → “내 전번째와 그 전전번째도 없기 때문이다”

<br/>

이렇기에 기저조건으로 내가 값을 채워 넣어야 되는 것이다.

## 궁금증!

```java
직접 재보면 차이가 얼마나 나나
```

호출 횟수를 세어봤다.

```java
fib(35) 단순 재귀 = 9227465  (53ms, 호출 29860703번)
fib(35) 메모      = 9227465  (0ms,  호출 69번)
```

<br/>

호출이 2986만 번과 69번이다.

<br/>

시간은 53ms와 0ms인데, 이건 `n=35` 라서 그렇다.

`n=45` 면 단순 재귀는 몇 초가 걸린다.

<br/>

## 호출이 69 번인 이유

`n=35` 인데 왜 35가 아니라 69일까.

<br/>

`fib(n)` 이 `fib(n-1)` 과 `fib(n-2)` 를 부르는데,

`fib(n-2)` 는 이미 계산되어 있어서 바로 돌아온다.

```java
실제 계산 = 34 번
저장된 것을 읽고 바로 반환 = 35 번
합계 = 69 번
```

<br/>

`저장된 것을 읽는 호출` 도 호출은 호출이다.

<br/>

상향식으로 하면 이 호출조차 없다.

```java
for (int i = 2; i <= n; i++) dp[i] = dp[i-1] + dp[i-2];
```

<br/>

반복문 34번이면 끝이다.

<br/>

## memo[n] != 0 을 조건으로 쓰면 안 되는 경우

```java
if (memo[n] != 0) return memo[n];
```

<br/>

피보나치는 `fib(0) = 0` 이라 `0` 이 유효한 답이다.

<br/>

지금 코드는 `n < 2` 를 먼저 처리해서 문제가 안 되는데,

일반적으로는 위험한 패턴이다.

```java
0 이 답일 수 있으면 -> 매번 다시 계산한다
```

<br/>

앞의 인접 행렬 글에서 본 것과 같은 문제다.

`0` 을 `없음` 으로 쓰면 실제 `0` 과 구분이 안 된다.

<br/>

`-1` 로 초기화하는 게 안전하다.

```java
Arrays.fill(memo, -1);
if (memo[n] != -1) return memo[n];
```

<br/>

답이 음수일 수도 있으면 `Long` 배열에 `null` 을 쓴다.

<br/>

## 피보나치는 O(log n) 으로도 된다

행렬 거듭제곱을 쓰면 된다.

```java
[1 1]^n   [F(n+1) F(n)  ]
[1 0]   = [F(n)   F(n-1)]
```

<br/>

거듭제곱을 분할 정복으로 하면 `O(log n)` 이다.

```java
a^8 = (a^4)^2 = ((a^2)^2)^2      // 세 번의 제곱
```

<br/>

앞의 이진 탐색 글에서 본 `절반씩 줄이는` 발상이다.

<br/>

`n` 이 10억이어도 30번쯤이면 끝난다.

<br/>

DP가 `O(n)` 인데 이건 `O(log n)` 이니 더 빠르다.

`DP 가 항상 최선은 아니다` 는 예시로 자주 나온다.

<br/>

## 일반항 공식도 있다

```java
F(n) = (φⁿ - ψⁿ) / √5
```

<br/>

`O(1)` 처럼 보이는데 실제로는 못 쓴다.

<br/>

앞의 실수 표현 글에서 본 부동소수점 오차 때문이다.

`n` 이 70쯤 넘으면 값이 틀리기 시작한다.

<br/>

`√5` 를 정확히 표현할 수 없으니 어쩔 수 없다.

<br/>

`수학적으로 맞는 것` 과 `컴퓨터에서 계산할 수 있는 것` 이 다른 예다.

<br/>

## 피보나치가 예제로 자주 쓰이는 이유

DP의 두 조건을 아주 단순하게 보여주기 때문이다.

```java
최적 부분 구조 - fib(n) 은 fib(n-1) 과 fib(n-2) 로 만들어진다
중복 부분 문제 - fib(n-2) 가 양쪽에서 계속 나온다
```

<br/>

앞의 동적 계획법의 개념 글에서 본 그 조건이다.

<br/>

그리고 개선 효과가 극적이다.

`O(2ⁿ)` 이 `O(n)` 이 되는 것을 이만큼 짧은 코드로 보여주는 예가 드물다.
