## 너비 우선 탐색 구현

```java
import java.util.Scanner;
import java.util.LinkedList;
import java.util.Queue;
import java.util.ArrayList;

// 너비 우선 탐색 (BFS)

// 1 ----- 2 ----- 6
//  \     / \     /
//   \   /   4 - 5
//    \ /   / \
//     3 - 7 - 8 - 9    

// ------------------
// 1
// ------------------

// DFS: 1 -> 2 -> 3 -> 7 -> 4 -> 5 -> 6 -> 8 -> 9
// BFS: 1 -> 2 -> 3 -> 4 -> 6 -> 7 -> 5 -> 8 -> 9

// 9 12
// 1 2
// 1 3
// 2 3
// 2 4
// 2 6
// 3 7
// 4 5
// 4 7
// 4 8
// 5 6
// 7 8
// 8 9

public class Main{
  
  static int n, m;
  static int MAX = 100;
  
  static ArrayList<Integer>[] myGraph = new ArrayList[MAX];
  
  
  public static void BFS() {
    // 1. 시작점을 큐에다가 삽입한다.
    // 2. 시작점을 색칠한다.
    
    // BFS 시작!
    
    // 3. 큐에서 하나를 뺀다. 애가 우리의 현재 위치이다.
    // 4. 인접한 모든 정점에게 방문했는지 물어보고
    //    방문을 하지 않았다면, 색칠하고 큐에 삽입한다.
    // 5. 모두 완료했다면 다시 3. 으로 돌아간다.
  
    Queue<Integer> queue = new LinkedList<>();
  
    boolean[] check = new boolean[MAX]; // true면 x가 색칠이 되어 있다는 뜻이다.
    
    queue.add(1); // 처음 1을 큐에 등록하기.
    check[1] = true;
    
    // 언제까지 반복문 돌리나? -> queue에서 아무것도 없을때 까지. 
    while(!queue.isEmpty()) { // 큐에 뭔가 들어있다면 반복을 해라 
                  // 부정이 뭐다? true면 전체를 false 바꾸고 
                  // false 면 전체를 true로 바꾸는 것이다.
      
      
      int current = queue.poll(); // front() 이렇게 한다면 
																  // 내 현재위치가 current 라는 것을 알게 되는 것이다.
      
      System.out.print(current + " "); // 방문 했다.
      
      for(int i = 0; i < myGraph[current].size(); i++) { // 노드 갯수 많은 for문 돌리기
        int next = myGraph[current].get(i);
        // current --- next 랑 연결되어 있는 것을 알 수 있는 것이다.
        
        if(check[next] == false) {
          check[next] = true;
          queue.add(next);
        }
      }
      
    }
    
  }

  public static void main(String[] args){

    Scanner sc = new Scanner(System.in);
    
    for(int i = 0; i < MAX; i++) {
      myGraph[i] = new ArrayList<Integer>();
    }

    n = sc.nextInt();
    m = sc.nextInt();
    
    for(int i = 0; i < m; i++) {
      
      int a = sc.nextInt();
      int b = sc.nextInt();
      
      myGraph[a].add(b);
      myGraph[b].add(a);
    }
     
     BFS();
      
    }
}
```

## 궁금증!

```java

```

큐의 크기를 미리 재두면 된다.

```java
int level = 0;
while (!queue.isEmpty()) {

    for (int i = 0; i < size; i++) {

        }

```

<br/>

`size` 를 반복문 안에서 부르면 안 된다.

돌면서 큐가 커지니 다음 층까지 같이 처리해버린다.

## 거리 배열을 쓰면 이게 필요 없다

```java
int[] dist = new int[n];
Arrays.fill(dist, -1);
dist[start] = 0;

while (!queue.isEmpty()) {
    int now = queue.poll();
    for (int next : adj[now]) {
        if (dist[next] == -1) {
            dist[next] = dist[now] + 1;
            queue.offer(next);
        }
    }
}
```

<br/>

앞의 그래프 순회의 뜻 글에서 본 방식이다.

`-1` 이 방문 여부를 겸한다.

<br/>

각 정점의 거리를 따로 알 수 있으니 층을 세는 것보다 유연하다.

<br/>

층 단위 처리가 필요한 경우는 `이 층 전체를 한꺼번에 봐야 할 때` 다.

이진 트리의 레벨 순회 출력 같은 것이다.

<br/>

## 넣을 때 표시해야 한다

앞의 그래프 순회의 뜻 글에서 본 그 실수다.

```java
// 틀린 코드
int now = queue.poll();
visited[now] = true;              // 꺼낼 때 표시
```

<br/>

같은 정점이 큐에 여러 번 들어간다.

<br/>

정점이 10만 개인 조밀한 그래프면 큐가 수백만 개로 불어난다.

메모리가 터지거나 아주 느려지는 것이다.

<br/>

## ArrayDeque 를 쓴다

```java
Queue<Integer> queue = new ArrayDeque<>();
```

<br/>

앞의 큐 글에서 본 대로 `LinkedList` 보다 빠르다.

<br/>

`null` 을 못 넣는다는 제약이 있는데, BFS에서는 상관없다.

정점 번호를 넣으니 `null` 이 들어갈 일이 없다.

<br/>

## 최단 경로를 복원하려면

거리만으로는 `어떤 길로 갔는지` 를 모른다.

```java
int[] prev = new int[n];
Arrays.fill(prev, -1);

if (dist[next] == -1) {
    dist[next] = dist[now] + 1;
    prev[next] = now;              // 어디서 왔는지 기록
    queue.offer(next);
}
```

<br/>

도착점에서 거꾸로 따라가면 경로가 나온다.

```java
List<Integer> path = new ArrayList<>();
for (int at = target; at != -1; at = prev[at]) {
    path.add(at);
}
Collections.reverse(path);
```

<br/>

앞의 연결 리스트 표현 글에서 본 것과 같은 구조다.

`앞을 가리키는 참조를 따라가는` 것이다.

<br/>

## 0-1 BFS 라는 것이 있다

간선 가중치가 0 아니면 1일 때 쓴다.

```java
Deque<Integer> deque = new ArrayDeque<>();

if (weight == 0) deque.addFirst(next);      // 앞에 넣는다
else             deque.addLast(next);       // 뒤에 넣는다
```

<br/>

가중치 0이면 거리가 안 늘어나니 지금 층에 속한다.

그래서 앞에 넣어 먼저 처리하는 것이다.

<br/>

앞의 큐 글에서 본 `Deque` 를 양쪽으로 쓰는 셈이다.

<br/>

다익스트라를 쓰면 `O(E log V)` 인데 이건 `O(V + E)` 다.

우선순위 큐가 필요 없어서 더 빠르다.

<br/>

## 다익스트라와의 관계

```java
BFS         - 큐. 가중치가 전부 같을 때
0-1 BFS     - 덱. 가중치가 0 또는 1
다익스트라   - 우선순위 큐. 가중치가 양수
```

<br/>

전부 `가까운 것부터 처리한다` 는 같은 발상이다.

`가까운 것을 어떻게 고르느냐` 만 다르다.

<br/>

가중치가 같으면 먼저 들어온 것이 가장 가까우니 큐면 충분하다.

가중치가 다르면 우선순위 큐가 필요해지는 것이다.

<br/>

앞의 큐 글에서 본 `PriorityQueue` 가 그 자리에 들어간다.

<br/>

## 양방향 BFS

시작점과 도착점에서 동시에 퍼뜨린다.

```java
한쪽에서 퍼지면 - 반지름 d 의 원
양쪽에서 퍼지면 - 반지름 d/2 의 원 두 개
```

<br/>

넓이가 지수적으로 늘어나는 그래프면 차이가 크다.

```java
분기 계수 b, 거리 d
단방향 - O(b^d)
양방향 - O(b^(d/2)) × 2
```

<br/>

구현이 까다로워서 잘 안 쓰는데,

체스 같은 상태 공간 탐색에서는 이 차이가 결정적이다.
