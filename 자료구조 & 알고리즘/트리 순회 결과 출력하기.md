## 트리 순회 결과 출력하기

```java
import java.util.Arrays;
import java.util.Scanner;

public class aaa {

  static int n;
  static int[][] tree;

  // 전위순회
  public static void preOrder(int x) {
    if (tree[x][0] == -1 && tree[x][1] == -1) {
      System.out.print(x + " ");

    } else {
      System.out.print(x + " ");

      if (tree[x][0] != -1) {
        preOrder(tree[x][0]);
      }

      if (tree[x][1] != -1) {
        preOrder(tree[x][1]);
      }
    }
  }

  // 중위순회
  public static void inOrder(int x) {
    if (tree[x][0] == -1 && tree[x][1] == -1) {
      System.out.print(x + " ");

    } else {
      if (tree[x][0] != -1) {
        inOrder(tree[x][0]);
      }

      System.out.print(x + " ");

      if (tree[x][1] != -1) {
        inOrder(tree[x][1]);
      }
    }
  }

  // 후위순회
  public static void postOrder(int x) {
    if (tree[x][0] == -1 && tree[x][1] == -1) {
      System.out.print(x + " ");

    } else {
      if (tree[x][0] != -1) {
        postOrder(tree[x][0]);
      }

      if (tree[x][1] != -1) {
        postOrder(tree[x][1]);
      }

      System.out.print(x + " ");
    }
  }

  public static void main(String[] args) {

    Scanner sc = new Scanner(System.in);

    n = sc.nextInt();
    tree = new int[n][2];

    for (int i = 0; i < n; i++) {
      int a = sc.nextInt();
      int b = sc.nextInt();
      int c = sc.nextInt();

      tree[a][0] = b; // 0은 left
      tree[a][1] = c; // 1은 right
    }

    preOrder(0);
    System.out.println();

    inOrder(0);
    System.out.println();

    postOrder(0);

  }
}
```
<br/>

## 궁금증!

```java
순회 결과로 트리를 되살릴 수 있나
```

하나로는 안 된다. 두 개가 있어야 한다.

```java
전위 = [1, 2, 4, 5, 3]
중위 = [4, 2, 5, 1, 3]
```

<br/>

전위의 첫 번째가 루트다. `1` 이다.

중위에서 `1` 의 위치를 찾으면 왼쪽과 오른쪽이 갈린다.

```java
중위 = [4, 2, 5] [1] [3]
        왼쪽 서브트리    오른쪽
```

<br/>

왼쪽이 세 개니, 전위에서도 루트 다음 세 개가 왼쪽이다.

```java
전위 = [1] [2, 4, 5] [3]
```

<br/>

이걸 재귀로 반복하면 트리가 복원된다.

<br/>

## 전위와 후위로는 안 된다

```java
전위 = [1, 2]
후위 = [2, 1]
```

<br/>

`2` 가 왼쪽 자식인지 오른쪽 자식인지 알 수가 없다.

<br/>

중위가 있어야 `루트를 기준으로 좌우가 나뉜다` 는 정보가 생긴다.

<br/>

정 이진 트리라면 전위+후위로도 된다.

자식이 0개 아니면 2개라는 제약이 애매함을 없애기 때문이다.

<br/>

## 트리를 문자열로 저장할 때

`null` 을 같이 적으면 하나로도 복원할 수 있다.

```java
전위 = [1, 2, 4, #, #, 5, #, #, 3, #, #]
```

<br/>

`#` 이 `자식 없음` 이다.

<br/>

앞의 트리의 개념 글에서 본 대로 모양이 확정되니 복원이 된다.

<br/>

리트코드의 트리 문제 입력이 이런 형태다.

```java
[1,2,3,null,null,4,5]
```

<br/>

이건 레벨 순회에 `null` 을 넣은 것이다.

<br/>

## 출력 형식을 정하는 게 은근히 일이다

```java
System.out.print(node.data + " ");
```

<br/>

이러면 끝에 공백이 하나 남는다.

<br/>

`StringBuilder` 로 모아서 마지막을 잘라내거나,

```java
sb.append(node.data).append(' ');
sb.setLength(sb.length() - 1);
```

<br/>

`String.join` 을 쓰는 게 낫다.

```java
List<String> result = new ArrayList<>();
// 순회하면서 result.add(...)
System.out.println(String.join(" ", result));
```

<br/>

앞의 String 클래스 글에서 본 대로,

`+` 로 이어 붙이면 반복마다 객체가 생긴다.

## 재귀에서 결과를 모으는 방법

```java
// 방법 1: 필드나 파라미터에 모은다
void inorder(Node n, List<Integer> result) {
    if (n == null) return;
    inorder(n.left, result);
    result.add(n.data);
    inorder(n.right, result);
}

// 방법 2: 반환값을 합친다
List<Integer> inorder(Node n) {
    if (n == null) return List.of();
    List<Integer> result = new ArrayList<>();
    result.addAll(inorder(n.left));
    result.add(n.data);
    result.addAll(inorder(n.right));
    return result;
}
```

<br/>

두 번째가 읽기는 좋은데 리스트를 계속 만들고 합친다.

<br/>

앞의 깊이 우선 탐색의 예제 글에서 본 것과 같은 거래다.

`공유하고 넘기기` 와 `복사하고 합치기` 중에 고르는 것이다.

<br/>

노드가 많으면 첫 번째가 낫다.

`addAll` 이 매번 복사라 전체가 `O(n²)` 이 되기 때문이다.

<br/>

## 출력을 순회에 섞지 않는 게 낫다

```java
void inorder(Node n) {
    ...
    System.out.print(n.data);      // 순회 안에서 출력
}
```

<br/>

이러면 테스트하기 어렵다.

<br/>

앞의 Postman 사용 이유 글에서 본 얘기와 이어진다.

`화면에 찍히는 것` 은 검증하기 번거롭다.

<br/>

리스트로 돌려주면 그냥 비교하면 된다.

```java
assertThat(inorder(root)).containsExactly(4, 2, 5, 1, 3);
```

<br/>

`무엇을 계산하는가` 와 `그것을 어떻게 보여주는가` 를 나누는 것이

앞의 MVC(=Model View Controller) 글에서 본 원칙과 같다.
