## 이벤트

### value 속성이란?

input 태그는 버튼이다. 이 버튼에 글씨를 사용하고 싶다면 value 속성을 사용하면 되는 것이다.

```html
<input type="button" value="hi">
```

<br/>

## 자바스크립트의 이벤트란?

사용자와 상호작용하는 웹페이지, 웹사이트를 만들 수 있다.

자바스크립트에서 약 10개에서 20개 정도 되는 이벤트 들을 정의해 놓고 있다.

대표적인 onlick, onchange, onkeydown 등등 속성 들을 이벤트라고 부른다.

<br/>

## onclick 속성이란?

이런 코드가 있다고 생각해보자.

웹 브라우저는 onclick 속성을 만나면 `alert('hi')` 를 기억하고 있다가

“사용자가 이 버튼을 클릭하면 그 때 실행 해야지” 하고 기다리는 것이다.

그리고 실제로 사용자가 ‘hi’ 버튼을 누르면 자바스크립트로 동작하는 것이다.

```html
<input type="button" value="hi" onclick="alert('hi')">
```

<br/>

참고로 alert() 은 팝업 창, 경고창 이다.

## onchange 속성이란?

이런 코드가 있다고 가정 해보자.

```html
<input type="text" onchange="alert('changed')">
```

<br/>이런 input 창이 있는데 인풋창에서 변화가 있을 시 실행되게 하는 것이다.

![이미지](/programming/img/js3.PNG)

<br/>실행 방법은 안에 내용을 작성 하고, 마우스를 다른곳으로 클릭하면 실행되는 것이다.

![이미지](/programming/img/js4.PNG)

<br/>

## onkeydown 속성이란?

이런 코드가 있다고 생각해보자.

인풋창에 키보드로 부터 값을 받으면 바로 팝업창이 출력 되는 것이다.

```html
<input type="text" onkeydown="alert('key down!')">
```

<br/>인풋 박스안에 바로 값을 넣자 마자 팝업창이 실행 되는 것이다.

![이미지](/programming/img/js5.PNG)

<br/>출력하기.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
</head>
<body>

    <input type="button" value="hi" onclick="alert('hi')">
    <input type="text" onchange="alert('changed')">
    <input type="text" onkeydown="alert('key down!')">

</body>
</html>
```

<br/>

대충 어떤 느낌인지 이제 알 것이다.

## 궁금증!

```java
setTimeout(0) 이 왜 바로 안 도는가
```

실행 순서를 찍어봤다.

```javascript
console.log("1 동기");
setTimeout(() => console.log("4 setTimeout"), 0);
Promise.resolve().then(() => console.log("3 Promise"));
console.log("2 동기");
```

<br/>

### 결과

```javascript
1 동기
2 동기
3 Promise (마이크로태스크)
4 setTimeout (매크로태스크)
```

<br/>

`0` 밀리초인데 제일 마지막에 돈다.

<br/>

## 큐가 두 개다

```java
동기 코드가 전부 끝난다
-> 마이크로태스크 큐를 전부 비운다 (Promise)
-> 매크로태스크를 하나 처리한다 (setTimeout, 이벤트)
-> 다시 마이크로태스크를 비운다
-> 반복
```

<br/>

마이크로태스크가 우선이다.

<br/>

`setTimeout(0)` 은 `0 밀리초 뒤` 가 아니라

`지금 하던 일이 끝나면` 이라는 뜻인 것이다.

<br/>

앞의 큐 글에서 본 큐가 두 벌 있는 셈이다.

<br/>

## 그래서 무거운 작업이 화면을 멈춘다

```javascript
for (let i = 0; i < 1000000000; i++) { }
```

<br/>

이게 도는 동안 클릭도 안 되고 화면도 안 그려진다.

<br/>

자바스크립트는 스레드가 하나이기 때문이다.

<br/>

앞의 멀티 쓰레드 글에서 본 자바의 방식과 정반대다.

```java
자바     - 요청마다 스레드. 하나가 막혀도 다른 것은 돈다
자바스크립트 - 스레드 하나. 하나가 막히면 전부 멈춘다
```

<br/>

그래서 무거운 계산은 나눠서 돌리거나 `Web Worker` 로 뺀다.

<br/>

## 이벤트 전파가 두 단계다

```java
캡처링 - 바깥에서 안으로 내려온다
버블링 - 안에서 바깥으로 올라간다
```

<br/>

기본은 버블링이다.

```javascript
element.addEventListener('click', handler);              // 버블링
element.addEventListener('click', handler, true);        // 캡처링
```

<br/>

버튼을 누르면 버튼 -> 부모 -> 조부모 순으로 올라간다.

<br/>

## 이걸 이용한 것이 이벤트 위임이다

```javascript
list.addEventListener('click', (e) => {
    if (e.target.matches('.item')) {
        // 항목 클릭 처리
    }
});
```

<br/>

항목마다 리스너를 붙이는 대신 부모에 하나만 붙인다.

<br/>

```java
항목 1000 개 -> 리스너 1000 개
이벤트 위임  -> 리스너 1 개
```

<br/>

메모리도 아끼고, 나중에 추가된 항목도 자동으로 동작한다.

<br/>

동적으로 만든 요소에 이벤트가 안 걸리는 문제가 이걸로 해결된다.

<br/>

## target 과 currentTarget 이 다르다

```java
e.target        - 실제로 눌린 요소
e.currentTarget - 리스너가 붙어 있는 요소
```

<br/>

이벤트 위임에서는 이 둘이 다르다.

<br/>

```javascript
e.target        -> 눌린 항목
e.currentTarget -> list
```

<br/>

화살표 함수 안에서 `this` 는 `currentTarget` 이 아니다.

앞의 Function() 글에서 본 대로 바깥 `this` 를 쓰기 때문이다.

<br/>

일반 함수로 쓰면 `this === e.currentTarget` 이다.

<br/>

## 전파를 막는 두 가지

```javascript
e.stopPropagation()   - 위로 안 올라간다
e.preventDefault()    - 기본 동작을 막는다 (링크 이동, 폼 제출)
```

<br/>

둘을 헷갈리기 쉽다.

<br/>

```javascript
form.addEventListener('submit', (e) => {
    e.preventDefault();      // 페이지가 새로고침되는 것을 막는다
    fetch(...);
});
```

<br/>

앞의 Ajax 글에서 본 그 처리다.

폼 제출의 기본 동작이 페이지 이동이라 막아야 하는 것이다.

<br/>

`stopPropagation` 을 남발하면 안 된다.

부모에 붙은 리스너가 조용히 안 돌게 되어서 원인을 찾기 어려워진다.

<br/>

## 리스너를 떼는 것도 중요하다

```javascript
element.removeEventListener('click', handler);
```

<br/>

익명 함수로 붙이면 뗄 수가 없다.

```javascript
element.addEventListener('click', () => {...});      // 못 뗀다
```

<br/>

같은 참조여야 떼어지기 때문이다.

<br/>

안 떼면 앞의 Function() 글에서 본 클로저가 계속 살아 있는다.

<br/>

화면을 갈아 끼우는 SPA에서 이게 메모리 누수가 된다.

<br/>

`AbortController` 로 한꺼번에 뗄 수 있다.

```javascript
const ac = new AbortController();
element.addEventListener('click', handler, { signal: ac.signal });
ac.abort();      // 한 번에 전부 뗀다
```
