## 캐시 적용

- 캐시 덕분에 캐시 가능 시간동안 네트워크를 사용하지 않아도 된다.

- 빠른 사용자 경험

## 궁금증!

```java
캐시가 있고 없고를 헤더로 어떻게 지정할까?
```

`Cache-Control` 하나로 정한다. 서버가 응답할 때 붙인다.

```java
Cache-Control: no-store          - 저장하지 마라
Cache-Control: max-age=60        - 60초 동안은 그냥 써라
Cache-Control: no-cache          - 저장은 하되 쓸 때마다 물어봐라
```

<br/>

직접 띄운 서버로 확인해보면 이렇게 나온다.

```java
$ curl -i http://localhost:18083/max-age

HTTP/1.1 200 OK
Cache-Control: max-age=60
Content-length: 41
```

<br/>

`60` 초 안에 같은 주소를 다시 요청하면 브라우저는 서버에 아예 안 간다.

캐시에서 바로 꺼내 쓴다.

<br/>

## 그래서 세 단계가 있는 셈이다

```java
1. max-age 안 -> 요청 자체를 안 보낸다        (네트워크 0)
2. max-age 지남 -> 검증 요청을 보낸다
     내용이 그대로면 -> 304 (헤더만 받는다)
     바뀌었으면    -> 200 (본문을 다시 받는다)
```

<br/>

앞의 검증 헤더 글에서 본 `304` 가 `2번` 의 결과다.

<br/>

`max-age` 는 왕복 자체를 없애고, 검증 헤더는 왕복은 하되 본문을 안 받는다.

둘을 같이 쓰는 것이 보통이다.

```java
Cache-Control: max-age=60
ETag: "v1-abc123"
```

<br/>

## 캐시가 없으면 무슨 일이 생기는가

원문의 그림을 숫자로 바꿔보면 이렇다.

```java
이미지 하나가 500 KB
페이지에 이미지가 20 개
페이지를 5 번 본다

캐시 없음 - 500 KB × 20 × 5 = 50 MB
캐시 있음 - 500 KB × 20 × 1 = 10 MB  (나머지 4 번은 0)
```

<br/>

그리고 네트워크 왕복도 `100` 번에서 `20` 번으로 준다.

앞의 DBCP 글에서 본 것과 같은 얘기다. 왕복 한 번이 수 밀리초씩 든다.

<br/>

## 캐시를 어디에 둘 것인가

브라우저만 캐시하는 것이 아니다.

```java
브라우저 캐시     - 사용자 한 명에게만 적용된다
프록시 캐시 (CDN) - 여러 사용자가 공유한다
```

<br/>

`Cache-Control` 로 어느 쪽에 저장할지도 정한다.

```java
Cache-Control: public   - 프록시도 저장해도 된다
Cache-Control: private  - 브라우저만 저장해라 (기본값)
```

<br/>

`private` 이 기본인 이유가 있다.

로그인한 사용자의 페이지를 프록시가 저장해두면, 다음 사람에게 남의 정보가 나간다.

<br/>

이미지나 CSS처럼 누구에게나 같은 것만 `public` 으로 둔다.

<br/>

## 캐시가 오히려 문제가 되는 순간

배포했는데 사용자에게 옛 화면이 보이는 경우다.

```java
app.js 를 고쳐서 배포했다
-> 브라우저 캐시에 아직 옛 app.js 가 남아 있다
-> max-age 가 안 끝나서 새로 안 받는다
-> 사용자는 새로고침해도 옛 코드를 본다
```

<br/>

`강력 새로고침` 을 안내하는 상황이 이것이다. 그런데 사용자에게 그걸 시킬 수는 없다.

<br/>

그래서 앞의 검증 헤더 글에서 본 대로 파일 이름에 해시를 넣는다.

```html
<script src="/js/app.a1b2c3d4.js"></script>
```

<br/>

내용이 바뀌면 이름이 바뀌니 캐시에 없는 새 주소가 된다.

`HTML` 만 캐시하지 않게 두면, 새 HTML이 새 파일 이름을 가리키면서 자동으로 갱신된다.

```java
index.html  - no-cache (항상 확인한다)
app.해시.js - max-age=31536000 (1년. 이름이 바뀌니 안전하다)
```
