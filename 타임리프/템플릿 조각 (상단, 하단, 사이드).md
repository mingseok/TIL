## 템플릿 조각

웹 페이지를 개발할 때는 공통 영역이 많이 있다. 

예를 들어서 상단 영역이나 하단 영역, 좌측 카테고리 등등

<br/>여러 페이지에서 함께 사용하는 영역들이 있다. 

이런 부분을 코드를 복사해서 사용한다면 변경시 여러 페이지를 다 수정해야 하므로 상당히 비효율 적이다. 

<br/>타임리프는 이런 문제를 해결하기 위해 템플릿 조각과 레이아웃 기능을 지원한다.

```html
th:fragment 가 있는 태그는 다른곳에 포함되는 코드 조각으로 이해하면 된다
```

template/fragment/footer :: copy : template/fragment/footer.html 템플릿에 있는

th:fragment="copy" 라는 부분을 템플릿 조각으로 가져와서 사용한다는 의미이다.

<br/><br/>

## 컨트롤러

```java
@Controller
@RequestMapping("/template")
public class TemplateController {
    
    @GetMapping("/fragment")
    public String template() {
        return "template/fragment/fragmentMain";
    }
}
```

<br/><br/>

## footer.html

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<body>

<footer th:fragment="copy">
    푸터 자리 입니다.
</footer>

<footer th:fragment="copyParam (param1, param2)">
    <p>파라미터 자리 입니다.</p>
    <p th:text="${param1}"></p>
    <p th:text="${param2}"></p>
</footer>

</body>
</html>
```

<br/><br/>

## fragmentMain.html

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
</head>
<body>
    <h2>부분 포함 insert</h2>
    <div th:insert="~{template/fragment/footer :: copy}"></div>

    <h2>부분 포함 replace</h2>
    <div th:replace="~{template/fragment/footer :: copy}"></div>

    <h2>부분 포함 단순 표현식</h2>
    <div th:replace="template/fragment/footer :: copy"></div>

    <h1>파라미터 사용</h1>
    <div th:replace="~{template/fragment/footer :: copyParam ('데이터1', '데이터2')}"></div>
</body>
</html>
```

<br/>

### footer.html 의 copy 부분

```html
<footer th:fragment="copy">
 푸터 자리 입니다.
</footer>
```

## 부분 포함 insert

```html
<div th:insert="~{template/fragment/footer :: copy}"></div>
```

<br/>출력되는 형태

```html
<h2>부분 포함 insert</h2>
<div>
<footer>
푸터 자리 입니다.
</footer>
</div>
```

th:insert 를 사용하면 현재 태그( div ) 내부에 추가한다.

<br/><br/>

## 부분 포함 replace

```html
<div th:replace="~{template/fragment/footer :: copy}"></div>
```

<br/>

출력되는 형태

```html
<h2>부분 포함 replace</h2>
<footer>
푸터 자리 입니다.
</footer>
```

th:replace 를 사용하면 현재 태그( div )를 대체한다.

<br/><br/>

## 부분 포함 단순 표현식

```html
<div th:replace="template/fragment/footer :: copy"></div>
```

<br/>

출력되는 형태

```html
<h2>부분 포함 단순 표현식</h2>
<footer>
푸터 자리 입니다.
</footer>
```

~{...} 를 사용하는 것이 원칙이지만 템플릿 조각을 사용하는 코드가 단순하면 이 부분을 생략할 수 있다.

<br/><br/>

## 파라미터 사용

다음과 같이 파라미터를 전달해서 동적으로 조각을 렌더링 할 수도 있다.

```html
<div th:replace="~{template/fragment/footer :: copyParam ('데이터1', '데이터2')}">
</div>
```

<br/>

출력되는 형태
```html
<h1>파라미터 사용</h1>
<footer>
<p>파라미터 자리 입니다.</p>
<p>데이터1</p>
<p>데이터2</p>
</footer>
```

## 궁금증!

```java
insert 와 replace 가 무엇이 다른가
```

껍데기 태그가 남느냐 아니냐다.

```html
<footer th:fragment="copy">
    <p>2026 부트캣</p>
</footer>
```

```html
<div th:insert="~{footer :: copy}"></div>
<div th:replace="~{footer :: copy}"></div>
```

<br/>

### 결과

```html
<!-- insert: div 안에 넣는다 -->
<div>
    <footer><p>2026 부트캣</p></footer>
</div>

<!-- replace: div 를 대체한다 -->
<footer><p>2026 부트캣</p></footer>
```

<br/>

`insert` 는 껍데기 `div` 가 남는다.

<br/>

## 대개 replace 가 맞다

의미 없는 `div` 가 쌓이면 CSS를 짤 때 걸리적거린다.

<br/>

앞의 블록 글에서 본 것과 같은 문제다.

`결과에 남으면 안 되는 자리` 가 템플릿에는 자꾸 생긴다.

<br/>

`insert` 를 쓸 때는 껍데기에 클래스를 줄 목적일 때다.

```html
<div class="footer-wrap" th:insert="~{footer :: copy}"></div>
```

<br/>

## 표기법이 세 가지다

```html
th:replace="~{footer :: copy}"      <!-- 정식 -->
th:replace="footer :: copy"         <!-- ~{} 생략 -->
th:replace="::copy"                 <!-- 같은 파일 안의 조각 -->
```

<br/>

파일 이름을 생략하면 지금 파일에서 찾는다.

<br/>

`~{...}` 를 생략할 수 있는데, 파라미터를 넘길 때는 생략하면 헷갈린다.

<br/>

## 파라미터를 넘길 수 있다

```html
<div th:fragment="card(title, content)">
    <h3 th:text="${title}"></h3>
    <p th:text="${content}"></p>
</div>
```

```html
<div th:replace="~{fragments :: card('공지', '내용입니다')}"></div>
```

<br/>

이름으로도 넘길 수 있다.

```html
<div th:replace="~{fragments :: card(content='내용', title='공지')}"></div>
```

<br/>

순서를 안 지켜도 되니 파라미터가 많으면 이쪽이 낫다.

<br/>

앞의 팩토리 메서드 패턴 글에서 본 것과 같은 얘기다.

`이름이 있으면 순서를 안 외워도 된다.`

<br/>

## 조각을 재사용할 때 생기는 문제

```html
<div th:fragment="memberCard">
    <span th:text="${member.name}"></span>
</div>
```

<br/>

이 조각은 모델에 `member` 가 있어야만 동작한다.

<br/>

다른 화면에서 쓰려면 그 화면도 `member` 라는 이름으로 담아야 한다.

이름이 다르면 안 된다.

<br/>

파라미터로 받으면 이 문제가 없다.

```html
<div th:fragment="memberCard(m)">
    <span th:text="${m.name}"></span>
</div>
```

```html
<div th:replace="~{fragments :: memberCard(${writer})}"></div>
<div th:replace="~{fragments :: memberCard(${owner})}"></div>
```

<br/>

앞의 Java에서의 역할과 구현 글에서 본 것과 같은 발상이다.

`밖에서 넣어주면 안에서 무엇인지 몰라도 된다.`

<br/>

## 조각 안에서 또 조각을 쓸 수 있다

```html
<div th:fragment="card(title, body)">
    <h3 th:text="${title}"></h3>
    <div th:replace="${body}"></div>
</div>
```

```html
<div th:replace="~{fragments :: card('제목', ~{:: #content})}"></div>
<div id="content">
    <p>이 내용이 들어간다</p>
</div>
```

<br/>

조각 표현식을 파라미터로 넘기는 것이다.

<br/>

`~{:: #content}` 는 `지금 파일에서 id 가 content 인 것` 이라는 뜻이다.

앞의 CSS 선택자 글에서 본 그 선택자 문법을 쓴다.

<br/>

앞의 템플릿 레이아웃 글에서 다루는 방식의 기초가 이것이다.

<br/>

## 빈 조각과 조각 제거

```html
th:replace="~{}"          <!-- 아무것도 안 넣는다 -->
th:replace="~{::none}"    <!-- 태그 자체를 없앤다 -->
```

<br/>

조건에 따라 조각을 넣거나 뺄 때 쓴다.

```html
<div th:replace="${showFooter} ? ~{footer :: copy} : ~{}"></div>
```

<br/>

`~{}` 는 껍데기 `div` 를 남기고 안을 비운다.

`~{::none}` 은 `div` 까지 없앤다.

<br/>

`th:if` 로 감싸는 것과 결과가 같은데,

조각 표현식 안에서 처리하면 조건과 대상이 한 줄에 모인다.
