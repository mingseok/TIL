## html 파일

```html
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
</head>
<body>
<ul>
    <li>산술 연산
        <ul>
            <li>10 + 2 = <span th:text="10 + 2"></span></li>
            <li>10 % 2 == 0 = <span th:text="10 % 2 == 0"></span></li>
        </ul>
    </li>
    <li>비교 연산
        <ul>
            <li>1 > 10 = <span th:text="1 &gt; 10"></span></li>
            <li>1 gt 10 = <span th:text="1 gt 10"></span></li>
            <li>1 >= 10 = <span th:text="1 >= 10"></span></li>
            <li>1 ge 10 = <span th:text="1 ge 10"></span></li>
            <li>1 == 10 = <span th:text="1 == 10"></span></li>
            <li>1 != 10 = <span th:text="1 != 10"></span></li>
        </ul>
    </li>
    <li>조건식 -> 참이면 '짝수' / 거짓이면 '홀수'
        <ul>
            <li>(10 % 2 == 0)? '짝수':'홀수' = <span th:text="(10 % 2 == 0)?'짝수':'홀수'"></span></li>
        </ul>
    </li>
    <li>Elvis 연산자 -> ${data} 안에 데이터가 있으면 출력, 저 문구 출력.
        <ul>
            <li>${data}?: '데이터가 없습니다.' = <span th:text="${data}?: '데이터가없습니다.'"></span></li>
            <li>${nullData}?: '데이터가 없습니다.' = <span th:text="${nullData}?:'데이터가 없습니다.'"></span></li>
        </ul>
    </li>
    <li>No-Operation 밑에서 추가 설명
        <ul>
            <li>${data}?: _ = <span th:text="${data}?: _">데이터가 없습니다.</span>
            </li>
            <li>${nullData}?: _ = <span th:text="${nullData}?: _">데이터가없습니다.</span></li>
        </ul>
    </li>
</ul>
</body>
</html>

```

## No-Operation: _ 인 경우

마치 타임리프가 실행되지 않는 것 처럼 동작한다. 

이것을 잘 사용하면 HTML의 내용 그대로 활용할 수 있다. 

```html
<span th:text="${nullData}?: _">데이터가 없습니다.</span>
```

<br/><br/>

즉, 타임리프 렌더링을 안하는 것이랑 비슷하다.

결국 <span>데이터가 없습니다.</span> 랑 같게 되는 것이다.

‘_’ 를 ‘노 오퍼레이션’ 이라고 부른다.

## 궁금증!

```java
HTML 에서 부등호를 그냥 쓰면 안 되나
```

`<` 와 `>` 는 태그 기호라서 문제가 된다.

```html
<span th:if="${age > 20}">성인</span>       <!-- 애매하다 -->
```

<br/>

`>` 가 태그의 끝으로 해석될 수 있다.

<br/>

그래서 문자 표기가 따로 있다.

```java
>    gt
<    lt
>=   ge
<=   le
==   eq
!=   ne
```

<br/>

```html
<span th:if="${age gt 20}">성인</span>
```

<br/>

실제로는 속성값 안에 있으면 파서가 처리해주는 경우가 많아서

`>` 를 그대로 써도 대개 동작한다.

<br/>

문제가 되는 건 속성 밖이다.

```html
<div th:if="${a < b}">      <!-- 여기서 태그가 끊긴 것으로 볼 수 있다 -->
```

<br/>

그래서 `lt` 를 쓰는 게 안전하다.

<br/>

## 논리 연산자

```java
and, or, not
```

<br/>

기호가 아니라 단어다.

```html
<span th:if="${age ge 20 and grade eq 'GOLD'}">
```

<br/>

`&&` 를 쓰면 HTML에서 `&` 가 엔티티 시작 문자라 또 문제가 된다.

`&amp;&amp;` 로 써야 하는데 읽기 어려워진다.

<br/>

## 조건 연산자

```html
<span th:text="${age ge 20} ? '성인' : '미성년자'"></span>
```

<br/>

거짓일 때 아무것도 안 보이게 하려면 뒤를 생략할 수 있다.

```html
<span th:text="${age ge 20} ? '성인'"></span>
```

<br/>

`null` 이 되어 아무것도 안 나온다.

<br/>

## Elvis 연산자

```html
<span th:text="${name} ?: '이름 없음'"></span>
```

<br/>

`?:` 가 나란히 붙어 있는 모양이 엘비스 프레슬리의 머리 같다고 붙은 이름이다.

<br/>

`null` 일 때만 대체한다. 빈 문자열은 그대로 나온다.

```java
name = null   ->  '이름 없음'
name = ""     ->  ""
```

<br/>

앞의 조건부 if 글에서 본 그 함정과 같다.

`값이 없다` 를 무엇으로 볼지가 문제인 것이다.

<br/>

## No-Operation 이라는 게 있다

```html
<span th:text="${name} ?: _">기본 이름</span>
```

<br/>

밑줄이 `아무것도 하지 마라` 는 뜻이다.

<br/>

`name` 이 `null` 이면 `th:text` 자체가 없던 것처럼 동작해서,

태그 안에 원래 적혀 있던 `기본 이름` 이 그대로 나온다.

<br/>

앞의 타임리프 소개 글에서 본 내추럴 템플릿과 이어진다.

파일을 그냥 열었을 때 보이던 글자를 기본값으로 쓰는 것이다.

<br/>

디자이너가 넣어둔 예시 텍스트를 그대로 살릴 수 있어서,

`데이터가 없을 때 화면이 텅 비는` 문제를 안 만든다.

<br/>

## 산술 연산에서 조심할 것

```html
<span th:text="${price * count}"></span>
```

<br/>

정수끼리 나누면 소수점이 잘린다.

```html
<span th:text="${10 / 3}"></span>       <!-- 3 -->
```

<br/>

자바와 같은 규칙이다.

<br/>

금액 계산을 화면에서 하면 안 되는 이유이기도 하다.

앞의 실수 표현 글에서 본 부동소수점 문제까지 겹치면

화면마다 다른 값이 나올 수도 있다.

<br/>

계산은 서버에서 `BigDecimal` 로 끝내고 결과만 넘기는 게 낫다.

<br/>

## 숫자 표시는 유틸을 쓴다

```html
<span th:text="${#numbers.formatInteger(price, 3, 'COMMA')}"></span>
```

```java
1000000  ->  1,000,000
```

<br/>

두 번째 인자가 `최소 자릿수` 라는 게 헷갈린다.

`3` 은 세 자리마다 콤마가 아니라, 최소 세 자리로 채우라는 뜻이다.

```java
formatInteger(5, 3, 'COMMA')     ->  005
```

<br/>

세 자리 구분은 `'COMMA'` 가 하는 일이다.

<br/>

소수점이 있으면 다른 메서드를 쓴다.

```html
${#numbers.formatDecimal(price, 3, 'COMMA', 2, 'POINT')}
```

<br/>

앞의 스프링 타입 컨버터 글에서 본 `Formatter` 와 같은 일을 화면에서 하는 것이다.

<br/>

나라마다 표기가 다르니, 국제화가 필요하면

`@NumberFormat` 이나 메시지 파일 쪽으로 옮기는 게 낫다.
