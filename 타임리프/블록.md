## 블록

이렇게 each 문법을 사용하여 반복할 경우 div 태그를 하나만 반복 할 수 있는 것이다. 

```html
<div th:each="user : ${users}">>
    사용자 이름1 <span th:text="${user.username}"></span>
    사용자 나이1 <span th:text="${user.age}"></span>
</div>
```

<br/><br/>

## 하지만, 나는 div 태그 한번에 2번, 3번 ... 등 반복 시키고 싶은 것이다.

이렇게 블럭을 사용하면 두개 묶음으로 반복을 돌릴 수 있는 것이다.

```html
<th:block th:each="user : ${users}">

</th:block>
```

<br/><br/>

## 궁금증!

```java
th:block 이 왜 필요한가
```

반복하거나 감출 대상이 여러 태그일 때 쓸 데가 없기 때문이다.

```html
<div th:each="member : ${members}">
    <h3 th:text="${member.name}"></h3>
    <p th:text="${member.intro}"></p>
</div>
```

<br/>

`div` 하나가 회원마다 생긴다. 필요 없는 태그가 늘어난다.

<br/>

```html
<th:block th:each="member : ${members}">
    <h3 th:text="${member.name}"></h3>
    <p th:text="${member.intro}"></p>
</th:block>
```

<br/>

`th:block` 은 결과에 안 남는다.

`h3` 와 `p` 만 반복해서 나온다.

<br/>

## 표에서 특히 유용하다

```html
<table>
    <th:block th:each="member : ${members}">
        <tr><td th:text="${member.name}"></td></tr>
        <tr><td th:text="${member.address}"></td></tr>
    </th:block>
</table>
```

<br/>

회원 하나가 두 줄로 표시되는 경우다.

<br/>

`table` 안에는 `div` 를 넣을 수 없다. HTML 스펙이 그렇다.

넣으면 브라우저가 표 밖으로 밀어내버린다.

<br/>

`th:block` 은 결과에 안 남으니 이 문제가 없다.

<br/>

## 조건에도 쓴다

```html
<th:block th:if="${isAdmin}">
    <button>수정</button>
    <button>삭제</button>
</th:block>
```

<br/>

버튼 두 개를 묶어서 감추는데 껍데기 태그가 안 생긴다.

<br/>

앞의 조건부 if 글에서 본 대로,

`th:if` 는 태그를 아예 안 만드는 것이라 이 안의 버튼들이 응답에 없다.

<br/>

## 리액트의 Fragment 와 같은 발상이다

```javascript
<>
  <h3>{name}</h3>
  <p>{intro}</p>
</>
```

<br/>

리액트도 같은 문제를 겪는다.

컴포넌트는 하나를 반환해야 하는데, 감싸려고 `div` 를 두면 DOM이 지저분해진다.

<br/>

`앞뒤로 무언가 표시가 필요하지만 결과에는 남으면 안 되는` 자리가

템플릿 언어에는 항상 생기는 것이다.

<br/>

## 자바스크립트 안에서도 쓸 수 있다

```html
<script th:inline="javascript">
    /*[# th:each="member : ${members}"]*/
    console.log([[${member.name}]]);
    /*[/]*/
</script>
```

<br/>

주석 안에 `[# ... ]` 형태로 적는다.

<br/>

주석이라 브라우저로 그냥 열어도 문법 오류가 안 난다.

내추럴 템플릿의 성질을 자바스크립트에서도 지키려는 것이다.

<br/>

앞의 자바스크립트 인라인 each 글에서 다루는 방식이다.

<br/>

## 남용하면 읽기 어려워진다

```html
<th:block th:each="a : ${as}">
    <th:block th:if="${a.valid}">
        <th:block th:each="b : ${a.bs}">
```

<br/>

세 겹이 되면 어디가 어디인지 모른다.

<br/>

이 정도로 복잡해지면 조각으로 나누는 게 낫다.

앞의 템플릿 조각 글에서 본 `th:fragment` 를 쓰는 것이다.

<br/>

화면이 복잡해지는 것은 대개 넘겨받은 데이터가 화면에 안 맞기 때문이다.

컨트롤러에서 화면에 맞는 모양으로 만들어 넘기면 화면이 단순해진다.

<br/>

앞의 API 방식(json), @ResponseBody 글에서 본 DTO의 역할과 같다.

`화면이 필요한 모양` 을 서버에서 만들어주는 것이다.
