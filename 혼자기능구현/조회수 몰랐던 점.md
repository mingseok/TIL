## 조회수 기능 구현 몰랐던 점

필요한 부분은 `listStat.index+1` 이다 

해석하자면 디비에 있는 오토 인크리먼트 되어 있는 id 값을 무시하고 

게시판 페이지에 따라 맞춰서 게시판 번호를 출력 해준다는 것이다.

초기값이 0 으로 세팅 되어 있어서 +1 하엿다.

```html
<!DOCTYPE html>
<html lang="en"
      xmlns:th="http://www.thymeleaf.org">
<head th:replace="fragments.html :: head"></head>
<body>
<div th:replace="fragments.html :: main-nav"></div>
<div class="container">
    <table class="table table-hover" style="margin-top: 5%">
        <thead>
        <th>글번호</th>
        <th>작성자</th>
        <th>제목</th>
        <th>조회수</th>
        <th>날짜</th>
        </thead>
        <tr th:each="list :${list}">
            <td><span th:text="${listStat.index+1}"></span></td>
            <td>[[${list.writer}]]</td>
            <td>
                <a th:href="@{/post-view(id=${list.id})}">
                    [[${list.title}]]
                </a>
            </td>
            <td>[[${list.hit}]]</td>
            <td><span th:text="${#temporals.format(list.createdDate,'yyyy-MM-dd HH:mm')}">작성시간</span></td>
        </tr>
    </table>
</div>
</body>
</html>
```

<br/><br/>

## HTML 몰랐던 부분

- `<small>` 태그

- `<span>` 태그

줄 바꿈이 되지 않다는 점이다.



<br/><br/>

## 메시지 표현:**`#{...}`**

```html
<small class="form-text text-danger" th:if="${#fields.hasErrors('loginId')}" th:errors="*{loginId}">loginId Error</small>
```

html 안에서 자바 코드를 실행하고 그 결과를 렌더 하겠다 라고 생각하면 될것이다.

<br/>

```html
<span th:text="${message}">메시지</span>
```

th: text태그 안의 텍스트를 서버에서 전달 받은 값에 따라 표현하고자 할 때 사용된다.

<br/>

`<span th:text="${post.content}">message</span>` 이 경우 서버에서 post.content 라는 

변수가 있을 경우 message의 자리를 변수값으로 대체하게 된다.)

- 변수 표현식 : `${...}`

- 선택 변수 표현식 : `{...}`
- 메시지 표현 : `#{...}`
- 링크 URL 표현식 : `@{...}`
- 조각 표현식 : `~{...}`
<br/>

## 궁금증!

```java
listStat.index 는 어디서 나오는 값일까?
```

타임리프가 `th:each` 를 돌 때 자동으로 만들어주는 상태 객체다.

```html
<tr th:each="list, listStat : ${list}">
```

<br/>

원문 코드에는 `listStat` 을 선언한 곳이 없는데도 쓸 수 있다.

변수 이름 뒤에 `Stat` 을 붙인 이름이 기본으로 만들어지기 때문이다.

```html
th:each="list : ${list}"       ->  listStat 을 쓸 수 있다
th:each="post : ${posts}"      ->  postStat 을 쓸 수 있다
```

<br/>

## 그 안에 들어 있는 것들

```java
index  - 0 부터 시작하는 번호
count  - 1 부터 시작하는 번호
size   - 전체 개수
first  - 첫 번째인가
last   - 마지막인가
odd    - 홀수 번째인가
even   - 짝수 번째인가
```

<br/>

원문에서 `index + 1` 을 한 것은 `count` 를 쓰면 그대로 된다.

```html
<span th:text="${listStat.index + 1}"></span>
<span th:text="${listStat.count}"></span>          <!-- 같은 결과 -->
```

<br/>

`first` 와 `last` 는 목록 사이에 구분선을 넣을 때 쓴다.

```html
<hr th:unless="${listStat.last}">
```

<br/>

## 왜 DB 의 id 를 안 쓰고 순번을 매기는가

원문의 `오토 인크리먼트 된 id 값을 무시하고` 라는 부분이 중요한 판단이다.

```java
DB 의 id  - 1, 2, 5, 9, 12 ...   (삭제된 번호가 비어 있다)
화면 번호  - 1, 2, 3, 4, 5 ...    (항상 이어진다)
```

<br/>

글을 삭제하면 `id` 에 구멍이 생긴다.

그걸 그대로 보여주면 사용자가 `3번 글이 어디 갔지` 하고 이상하게 여긴다.

<br/>

그래서 화면 번호와 실제 `id` 를 분리한 것이다.

앞의 뷰 리졸버 글에서 본 `논리 이름과 물리 경로를 나눈다` 와 같은 발상이다.

```html
<td>[[${listStat.count}]]</td>                        <!-- 보여주는 번호 -->
<a th:href="@{/post-view(id=${list.id})}">            <!-- 실제로 쓰는 id -->
```

<br/>

## 그런데 페이징을 붙이면 깨진다

`index` 는 `현재 페이지 안에서의 순서` 다.

```java
1 페이지 : 1, 2, 3 ... 10
2 페이지 : 1, 2, 3 ... 10      <- 다시 1 부터 시작한다
```

<br/>

그래서 페이지 번호를 같이 계산해야 한다.

```html
<span th:text="${(page - 1) * pageSize + listStat.count}"></span>
```

<br/>

또는 역순으로 매기는 방식도 많이 쓴다.

```html
<span th:text="${totalCount - ((page - 1) * pageSize) - listStat.index}"></span>
```

<br/>

최신 글이 위에 오는 게시판에서 `가장 위가 가장 큰 번호` 가 되게 하는 것이다.

<br/>

## span 과 small 이 줄바꿈이 안 되는 이유

원문의 HTML 메모에 대한 답이다.

```java
블록 요소 (block)  - div, p, h1, table  -> 한 줄을 통째로 차지한다
인라인 요소 (inline) - span, small, a, strong -> 글자만큼만 차지한다
```

<br/>

`span` 은 글자 흐름 안에 들어가는 요소라 줄을 나누지 않는다.

<br/>

줄을 바꾸고 싶으면 CSS로 성질을 바꾸면 된다.

```css
span { display: block; }
```

<br/>

그리고 인라인 요소에는 `width` 나 위아래 `margin` 이 안 먹는다.

`display: inline-block` 으로 두면 인라인처럼 나란히 놓이면서 크기는 지정할 수 있다.

<br/>

## #temporals.format 이 하는 일

```html
<span th:text="${#temporals.format(list.createdDate,'yyyy-MM-dd HH:mm')}">
```

<br/>

`#temporals` 는 타임리프가 제공하는 도우미다. `LocalDateTime` 계열을 다룬다.

<br/>

앞의 스프링 메시지 적용하기 글에서 본 국제화와 이어지는 지점이 있다.

날짜 형식은 나라마다 다르다.

```java
한국 : 2026-01-01
미국 : 01/01/2026
```

<br/>

형식을 HTML에 박아두면 나라별로 바꿀 수가 없다.

메시지 파일에 형식을 두고 꺼내 쓰면 국제화가 된다.

```properties
date.format=yyyy-MM-dd HH:mm
```

```html
<span th:text="${#temporals.format(list.createdDate, #{date.format})}">
```

<br/>

앞의 스프링 타입 컨버터 글에서 본 `Formatter` 가 `Locale` 을 받는 이유도 같은 문제 때문이다.
