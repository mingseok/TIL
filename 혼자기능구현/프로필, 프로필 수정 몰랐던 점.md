## 궁금증!

```java
"? 는 null 을 감싸준다" 는 게 정확한 설명일까?
```

`?` 가 하는 일은 그것보다 크다. 앞의 JDBC 표준 인터페이스 글에서 본 그 자리다.

```java
// 문자열을 이어 붙이는 방식
String sql = "SELECT * FROM profile WHERE member_id = " + memberId;

// ? 로 넘기는 방식
String sql = "SELECT * FROM profile WHERE member_id = ?";
ps.setInt(1, memberId);
```

<br/>

`?` 를 쓰면 세 가지가 달라진다.

<br/>

### 첫번째) 따옴표를 안 붙여도 된다

```java
"WHERE login_id = " + loginId        -> WHERE login_id = minseok   (문법 오류)
"WHERE login_id = '" + loginId + "'" -> 따옴표를 직접 붙여야 한다
"WHERE login_id = ?"                 -> 드라이버가 알아서 처리한다
```

<br/>

`null` 도 마찬가지다. `setString(1, null)` 이면 드라이버가 `NULL` 로 넣어준다.

문자열로 붙이면 `null` 이라는 네 글자가 들어가버린다.

<br/>

원문의 `? 는 null 을 감싸준다` 가 이 부분을 말한 것으로 보인다.

<br/>

### 두번째) SQL 인젝션을 막는다

이쪽이 훨씬 중요하다.

```java
"WHERE login_id = '" + input + "'"
```

<br/>

`input` 에 `1' OR '1'='1` 을 넣으면 조건이 항상 참이 된다.

`1'; DROP TABLE members; --` 를 넣으면 테이블이 날아간다.

<br/>

`?` 는 SQL 구조를 먼저 보내고 값을 나중에 보낸다.

값에 무엇이 들어 있든 SQL 문법으로 해석되지 않는다.

<br/>

### 세번째) 실행 계획을 재사용한다

```sql
WHERE member_id = 1     -- 새 SQL
WHERE member_id = 2     -- 또 새 SQL
WHERE member_id = ?     -- 항상 같은 SQL
```

<br/>

앞의 database system 글에서 본 대로, DB는 SQL을 받으면 실행 계획을 짠다.

`?` 를 쓰면 그 계획을 한 번만 짜고 계속 쓴다.

<br/>

## MyBatis 에서는 #{} 가 그 역할이다

```xml
WHERE member_id = #{memberId}     <!-- PreparedStatement 의 ? 로 바뀐다 -->
WHERE member_id = ${memberId}     <!-- 문자열이 그대로 들어간다 -->
```

<br/>

앞의 MyBatis 설명 글에서 본 그 구분이다.

`${}` 를 쓰면 위의 인젝션 문제가 그대로 생긴다.

## where 는 조건이지 대입이 아니다

원문의 `= 라고 대입이 아님` 이 정확한 지적이다.

```sql
UPDATE profile SET bio = ? WHERE member_id = ?
                  ^^^^^^^        ^^^^^^^^^^^^^
                  여기는 대입      여기는 비교
```

<br/>

같은 `=` 인데 `SET` 뒤에서는 대입이고 `WHERE` 뒤에서는 비교다.

<br/>

이걸 헷갈리면 `WHERE` 를 빼먹는 사고가 난다.

```sql
UPDATE profile SET bio = '안녕';       -- WHERE 가 없으면 전체 행이 바뀐다
```

<br/>

앞의 DML/DDL 글에서 본 대로 `UPDATE` 도 트랜잭션 안이면 롤백할 수 있다.

`autocommit` 이 켜져 있으면 되돌릴 수 없다.

<br/>

그래서 `UPDATE` 나 `DELETE` 를 손으로 실행할 때는 `SELECT` 로 먼저 확인하는 습관이 안전하다.

```sql
SELECT * FROM profile WHERE member_id = 1;     -- 몇 행인지 먼저 본다
UPDATE profile SET bio = '안녕' WHERE member_id = 1;
```
